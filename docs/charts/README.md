# Wykresy i wizualizacje (MongoDB Compass / Atlas Charts)

W tym katalogu umieszczane są wyeksportowane zrzuty ekranu (`.png`) z aplikacji **MongoDB Compass** prezentujące 3 analizy statystyczne z zadania MapReduce:
1. `analiza_1_temperatura.png` – rozkład i ekstrema temperatur (`avg_temp`, `min_temp`, `max_temp`),
2. `analiza_2_wiatr.png` – analiza prędkości wiatru (`avg_wind`, `max_wind`),
3. `analiza_3_opady.png` – suma i maksima opadów (`total_prcp`, `max_prcp`).
